# My Space

A detailed, full-stack blog app built with Node.js, Express, and EJS templates. Features a complete in-memory CRUD architecture to seamlessly create, read, update, and delete posts dynamically via structural `:id` routes. Styled with an MVC-inspired folder layout and a sleek, modern, responsive Medium-style dark tech-grid CSS UI.

**Live Link:** [https://my-space-blog.onrender.com/]
